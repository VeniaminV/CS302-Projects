Haunted Maze Game Engine (Project) (C++) — 
• Designed and implemented an interactive C++ game engine using polymorphic class hierarchies to model age-specific obstacles (kids, teens, adults)
• Built a fully templated doubly linked list with recursive insertion, deletion, traversal, deep copy, and memory cleanup operations
• Applied manual memory management with dynamic allocation, destructors, copy constructors, and assignment operators (Rule of Three)
• Implemented extensive operator overloading for comparison, arithmetic, and stream I/O to enhance object interaction and usability
• Developed a menu-driven CLI game loop with runtime traversal of linked data structures to simulate player movement and obstacle interactions
