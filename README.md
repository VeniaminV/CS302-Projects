Racing Simulation with Recursive 2-3-4 Tree (project) (C++)

• Designed and implemented a fully recursive 2-3-4 tree to store and manage polymorphic Racer objects using dynamic memory allocation

• Built an abstract Racer base class with derived types (Dog, Monster, Kid), leveraging virtual functions, deep-copy semantics, and runtime polymorphism

• Implemented safe manual memory management using destructors, copy constructors, assignment operators, and a virtual clone (copy) interface

• Developed recursive algorithms for insertion, node splitting, traversal, display  and complete memory cleanup of the tree

• Created a recursive race simulation that updates racer state, applies RTTI (dynamic_cast), and determines winners based on runtime behavior
