Festival Vendor Management System (Project) (C++) —
• Designed and implemented a C++ application to manage festival vendors using multiple data structures, including a singly linked list (Cuisine), circular linked list (Entertainers), and vector-based storage (Trinkets)
• Built a polymorphic class hierarchy with dynamic memory management, implementing constructors, copy constructors, assignment operators, and destructors (Rule of Three)
• Implemented fully recursive algorithms for insertion, retrieval, deletion, traversal, deep copying, and memory cleanup of linked data structures
• Ensured safe manual memory handling using dynamic allocation, deep copy helpers, and recursive cleanup functions to prevent memory leaks
• Developed a menu-driven CLI enabling creation, retrieval, removal, and modification of vendors at runtime
