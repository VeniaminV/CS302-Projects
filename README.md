# CS 302 Projects

All my CS 302 programs from Portland State, combined into one repo. Each folder is one program, and the full commit history from the original repos is kept.

| Folder | What it is | Language |
| --- | --- | --- |
| [program-1-festival-vendors](program-1-festival-vendors) | Festival vendor manager using a singly linked list, a circular linked list, and vectors, with a polymorphic class hierarchy | C++ |
| [program-2-haunted-maze](program-2-haunted-maze) | Haunted maze game engine with a templated doubly linked list and age-specific obstacles | C++ |
| [program-3-racing-234-tree](program-3-racing-234-tree) | Racing simulation that stores polymorphic racers in a fully recursive 2-3-4 tree | C++ |
| [program-4-5-social-media-analytics](program-4-5-social-media-analytics) | Social media analytics tool with a class hierarchy, operator overloading, and a recursive BST, plus black-box and glass-box tests | Python |

Main things practiced: recursion, dynamic memory and the Rule of Three, polymorphism, templates, and operator overloading.
